# TRACE 黑曜石工作台视觉重构设计

## 目标

将现有偏浅色工程原型风格的分析工作台，重塑为高级、深沉、克制的“黑曜石研究室”。本次改造只调整品牌、视觉系统、布局比例、弹窗和响应式表现，不改变现有数据分析流程、API、领域模型或交互能力。

产品英文名确定为 **TRACE**。界面操作文字继续使用中文，以保证当前用户的操作效率；品牌副标识使用 `LOCAL ANALYSIS SYSTEM`。

## 已确认的问题

- 左侧项目栏当前宽度为 268px，项目、数据集和任务内容拥挤，缺少项目控制台应有的存在感。
- 浅灰纸张、青绿色强调色、网格背景和密集细边框让界面更像工程原型，缺少暗色产品应有的层次与材质。
- 中间工作台和右侧聊天区的比例不够稳定，聊天区容易压缩分析阅读空间。
- 模型配置弹窗使用常规表单堆叠，信息层级、厂商选择和操作区缺少整体设计。
- 中文品牌“迹析”不符合新的英文产品命名要求。

## 视觉概念：黑曜石研究室

TRACE 面向需要长时间阅读结论、核查证据和追踪执行过程的数据分析人员。界面应像一间低反光的夜间研究室：安静、精密、可靠。大胆之处只放在一条“金色证据轨迹”上，其余区域保持克制。

### 色彩系统

- `Obsidian` `#090B0D`：页面主背景。
- `Graphite` `#101316`：项目栏和聊天栏。
- `Carbon` `#15191D`：卡片、输入区和弹窗面板。
- `Fog Silver` `#E7E3DA`：主文字和高优先级数据。
- `Slate` `#83898F`：说明、标签和次级状态。
- `Old Gold` `#B99A5E`：关键结论、选中状态和证据轨迹。
- `Deep Gold` `#806A3D`：暗金边线与非交互装饰。
- `Danger` `#C46D62`：失败和拒绝状态。

暗金不作为通用按钮颜色。它只标记当前项目、当前结论、运行中的计划步骤、重要状态和主操作，避免整页泛金造成廉价感。

### 字体角色

- 品牌与大标题：使用系统可用的窄体无衬线字体组合，优先 `Bahnschrift`，中文回退到 `Microsoft YaHei UI`。
- 正文与操作文字：使用 `Inter`、`Noto Sans SC`、`Microsoft YaHei UI` 的系统回退组合。
- 数据、状态、编号与标签：使用 `Cascadia Mono`、`SFMono-Regular`、`Consolas`。

不新增网络字体或运行时依赖。字号通过明确的标题、正文、说明和数据层级建立节奏，大标题不再占据过多首屏空间。

### 材质与动效

- 移除浅色网格纸背景和青绿色系统。
- 通过相邻黑色层级、低对比度描边、内高光和轻微阴影区分区域，不使用大面积发光。
- 页面只保留短促的悬浮、选中和面板进入过渡；运行状态可使用低频暗金呼吸效果。
- 尊重 `prefers-reduced-motion`，关闭非必要动画。

## 桌面布局比例

桌面端继续使用固定视口的三栏结构，各栏独立滚动。

```text
┌────── Project console 328px ──────┬──── Analysis canvas flex / min 620px ────┬──── Conversation 400px ────┐
│ TRACE / model / projects / data   │ objective / finding / plan / artifacts  │ messages / approvals / input │
└───────────────────────────────────┴──────────────────────────────────────────┴─────────────────────────────┘
```

- 左侧项目栏：默认 328px；超宽屏可增至 340px。内容密度适中，项目名、数据文件名和任务目标获得更完整的可读宽度。
- 中间分析区：占据所有剩余宽度，桌面最小宽度为 620px，是页面主要视觉焦点。
- 右侧聊天区：默认 400px，随大屏限制在 380–440px；收起后中间分析区自动扩展。
- 分栏使用低对比度边线和层级差，不使用明亮实线切割。

## 左侧项目控制台

- 品牌区将“迹析”替换为 `TRACE`，副标识为 `LOCAL ANALYSIS SYSTEM`。
- 模型路由改为紧凑的运行状态模块，清晰显示厂商、模型和配置状态。
- 当前项目使用暗金轨迹和更明显的背景层级，不再依赖青色块。
- 数据集和任务列表增加行高与左右留白，长文本优先保留可辨识的开头并提供稳定的省略行为。
- 新建项目、上传数据等操作使用低调的文本按钮；主操作只在交互时出现暗金高光。

## 中间分析工作台

- 任务标题控制在更紧凑的尺度，状态置于同一信息带，降低首屏高度。
- “当前结论”是视觉核心：使用 Carbon 面板、雾银正文和左侧金色证据轨迹；长结论保持可展开。
- 计划和执行记录维持并列，但通过表面层级而不是密集边框分组。
- 计划步骤的编号、状态和连接线共同形成“证据轨迹”；运行中为暗金，完成后转为低亮银灰，失败使用克制红色。
- 分析产物改为更清晰的行式资产索引，类型、名称、说明和打开动作保持可扫读。

## 右侧聊天区

- 默认宽度 400px，使用比主画布更深的 Graphite 背景，视觉上退居协作工具区。
- 头部、消息流、审批区和输入框继续各司其职；消息流独立滚动，输入框固定在底部。
- 用户消息和 Agent 消息用轻微层级差区分，不使用高饱和聊天气泡。
- 工具执行消息保持折叠，改为低亮度日志行；审批卡使用更明确的风险色和主次按钮。
- 收起操作在头部保持可见；收起后中间工作台获得完整空间。

## 模型配置弹窗

- 桌面宽度约 760px，最大不超过视口宽度的 92%。
- 弹窗采用黑曜石遮罩、Carbon 主面板和柔和内高光，避免普通白底表单感。
- 内容拆为两部分：左侧为模型厂商选择，右侧为 Base URL、模型和 API Key 配置。
- 当前厂商使用暗金边线和状态标识；未选项保持低对比度。
- 底部操作区固定为取消与保存，保存是唯一高优先级按钮。
- 窄屏下改为单列，厂商选择横向或纵向堆叠，表单和操作按钮保持可达。

## 响应式行为

- `>= 1320px`：完整三栏，左侧 328px，聊天区 400–440px，中间弹性伸展。
- `980px–1319px`：左侧缩至 288px，聊天区变为覆盖式抽屉，中间保持主要宽度。
- `< 980px`：主画布优先；项目栏和聊天栏都作为覆盖式抽屉进入，不同时占用中间宽度。
- `< 640px`：主画布单列，计划与执行记录上下排列；弹窗改为接近全屏的单列面板。

## 交互与可访问性

- 所有按钮、输入框、选择器和折叠项保留清晰的键盘焦点，焦点色使用 Old Gold。
- 文字与背景保持足够对比度，次级文字不低于可读阈值。
- 状态不能只依靠颜色表达，继续保留状态文字或图形标识。
- 不改变现有可访问名称、表单行为、对话收起、审批、项目切换、上传、任务切换和模型配置流程。

## 实施边界

- 主要修改 `web/src/styles.css`，必要时对现有 React 结构增加少量包装或语义类名。
- 将品牌文案从“迹析”改为 `TRACE`，但保留中文操作界面。
- 不新增运行时依赖，不修改后端接口，不迁移现有项目数据，也不自动翻译用户创建的项目名称。
- 不进行与视觉重构无关的组件重写或业务重构。

## 测试与验收

- 现有前端测试全部通过，TypeScript 与 Vite 构建成功。
- 在当前真实项目数据下验证 1440×900、1280×720、1024×768 和 390×844 视口。
- 桌面大屏下左侧项目栏明显宽于当前版本，项目和任务名称可读性改善。
- 中间分析区始终是主要视觉区域；聊天区默认宽度稳定，收起后主区域正确扩展。
- 模型配置弹窗在桌面和移动视口下都无水平溢出，字段、厂商选择和操作按钮可达。
- 检查项目栏、中间画布和聊天栏独立滚动；长对话不改变页面总高度。
- 检查键盘焦点、减少动态效果和浏览器控制台，无新增错误或警告。
