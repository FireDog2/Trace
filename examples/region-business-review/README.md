# 区域经营复盘测试包

这是一套可以直接上传到“迹析”的合成经营数据，用来测试 Agent 的数据检查、汇总、对比、归因、异常识别、图表和报告能力。

## 文件

- `region_operations_2025.csv`：推荐优先使用，单表、144 行。
- `region_operations_2025.xlsx`：与 CSV 内容相同，额外包含格式化数据表、字段说明和问题清单。
- `questions.md`：可以直接复制到“分析目标”的用户问题。
- `expected_findings.md`：用于核对 Agent 是否抓住了数据中埋入的关键变化。

CSV 和 Excel 是同一份数据，请任选一个上传，不要同时上传，避免重复计算。

## 推荐测试流程

1. 在左侧创建项目，例如“2025 区域经营复盘”。
2. 上传 `region_operations_2025.csv`。
3. 从 `questions.md` 复制第 1 个问题并开始分析。
4. 任务完成后，在右侧对话框继续发送第 3、4、5 个问题，测试上下文延续和下钻分析。
5. 最后发送第 8 个问题，检查是否生成包含结论、证据和图表的管理报告。

## 数据特征

- 时间：2025 年 1—12 月。
- 区域：华北、华南、华东、西部。
- 产品：智能设备、企业服务、订阅会员。
- 粒度：月份 × 区域 × 产品，共 144 行。
- 货币单位：人民币元。
- 数据为专门设计的合成数据，不对应真实企业或客户。
