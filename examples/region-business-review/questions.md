# 可直接使用的用户问题

## 1. 快速体检

> 概括 2025 年收入、营业利润、订单量和利润率趋势，指出最值得关注的区域。请给出关键数字和证据引用。

观察 Agent 是否会先检查字段和数据质量，再形成总体判断。

## 2. 区域对比

> 哪个区域下半年利润表现恶化最明显？比较上半年与下半年的收入、营业利润和利润率，并按严重程度排序。

观察 Agent 是否会正确划分 H1/H2，并避免只比较收入。

## 3. 华东区归因

> 深入分析华东区下半年利润恶化的原因，量化收入、销售成本、物流成本、营销费用和产品结构的影响。不要只描述相关性，要给出各驱动因素的变化幅度。

这是本数据集最核心的归因问题。

## 4. 产品下钻

> 华东区哪个产品对利润下降贡献最大？比较三个产品上下半年的利润、利润率、退货率和满意度，并给出产品级证据。

观察 Agent 能否从区域继续下钻到产品。

## 5. 客户信号

> 退货率和满意度是否与利润变化同步？请按区域和月份验证，并说明这是因果关系还是经营预警信号。

观察 Agent 是否能区分相关性与因果性。

## 6. 目标达成

> 哪些区域和产品没有完成收入目标？计算目标达成率，列出差距最大的五个“月份 × 区域 × 产品”组合。

观察 Agent 是否能构造派生指标并正确排序。

## 7. 异常识别

> 识别数据中最明显的异常月份或异常组合。请说明异常检测口径、列出证据，并判断异常更像数据质量问题还是业务变化。

观察 Agent 是否会检查异常而不是直接把所有变化都当作错误数据。

## 8. 管理层报告

> 基于全部分析生成一份管理层经营复盘报告，包括：三条关键结论、区域和产品证据表、月度趋势图、主要风险、三条可执行建议，以及每条结论对应的证据引用。

观察最终报告、图表和证据链是否完整沉淀到任务工作台。

## 建议的连续追问

完成第 3 个问题后，可以在右侧对话框继续输入：

> 把华东和表现最稳定的区域做对照，找出两者成本结构和客户指标的最大差异。

然后继续输入：

> 如果华东区的物流成本率和营销费用率恢复到上半年水平，下半年营业利润大约可以改善多少？请写出假设和计算过程。
